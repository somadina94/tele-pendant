# Manual test plan (simulator)

Follow [USER_MANUAL.md](./USER_MANUAL.md) click by click. This table is the pass/fail list for the same order.

**Live:** web **https://hmi.example.com**, API **https://api.example.com**, Swagger **https://api.example.com/api**.  
**Local Docker:** web **http://localhost:8080**, API **http://localhost:3010**, Swagger **http://localhost:3010/api**.

Replace `localhost` hosts with the live hosts when verifying production.

Do the STOP rows last. E-stop latches until `docker restart tele-pendant-modbus-sim-dev`. Row 15 is Ops diagnostics.
